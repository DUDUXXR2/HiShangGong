# 目标
一次性修复 6 个问题：玻璃背景恢复、Cookie持久化、搜索框升级、WebView布局、原生按钮替换

## 1. 修复玻璃背景缺失（最高优先级）

### 问题根因
之前的 API 26 升级中，将 `GlassCard.ets`、`GlassPanel.ets`、`MineTab.ets` 的 `HdsTabs` 材质层（`ImmersionMaterialLayer` / `MaterialLayer`）替换成了 `systemMaterial(uiMaterial.ImmersiveMaterial)`。但 `systemMaterial()` 是纯色半透明毛玻璃，不包含 `HdsTabs` 的 `systemMaterialEffect` 带来的沉浸光感效果（渐变边缘、材质色彩映射等），导致卡片变为全透明/无视觉效果的空壳。

### 备份对照（E:\YSSG）
YSSG 使用 `HdsTabs` + `barFloatingStyle({ systemMaterialEffect })` 叠加方案：
- `GlassCard`: `MaterialLayer` builder 内嵌 `HdsTabs` → `barFloatingStyle({ systemMaterialEffect, gradientMask })`
- `GlassPanel`: 同上
- `MineTab`: `ImmersionMaterialLayer` 同样内嵌 `HdsTabs`
- 外层 Stack 叠加: 底层材质层(zIndex=1) + 内容层(zIndex=2)
- `cardSurfaceBaseColor()`: 材质启用时 `Color.Transparent`，禁用时回退纯色

### 修复方案
**恢复 YSSG 的 HdsTabs 材质层方案**，同时保留 API 26 `uiMaterial` 作为增强选项。

对每个组件：

#### [GlassCard.ets](entry/src/main/ets/components/GlassCard.ets)
- 恢复 `HdsTabs` + `barFloatingStyle({ systemMaterialEffect })` 的 `MaterialLayer` builder
- 恢复 `Stack({ alignContent: Alignment.Top })` 双层结构: MaterialLayer(zIndex=1) + content(zIndex=2)
- 恢复 `onAreaChange` 跟踪 cardWidth → expandedWidth
- 保留 `cardSurfaceBaseColor` / `cardSurfaceBorderWidth` / `immersionBorderColor` 辅助方法
- 保留 `configuredMaterialType()` / `configuredMaterialLevel()` 调用 `MaterialConfig`

#### [GlassPanel.ets](entry/src/main/ets/components/GlassPanel.ets)
- 同 GlassCard，恢复 HdsTabs 材质层

#### [MineTab.ets](entry/src/main/ets/pages/tabs/MineTab.ets)
- 恢复 `ImmersionMaterialLayer` / `ImmersionMaterialContent` / `ImmersionCardSurface` builders
- 恢复 `configuredMaterialType()` / `configuredMaterialLevel()` 方法
- 恢复 `cardSurfaceBorderWidth()` 方法
- 恢复三张卡片的 `ImmersionCardSurface` 叠加结构
- 移除之前添加的 `deviceInfo.apiAvailable` 条件渲染分支（不再需要，HdsTabs systemMaterialEffect API 23+ 可用）
- 移除 `uiMaterial` import（不再在此文件使用）
- 移除内联的三元 `systemMaterial` 样式表达式

## 3. 修复 WebView Cookie 持久化

### 问题
每次进入 WebView 页面（成绩、课表、电费等）都需要重新登录。安卓版不会。

### 根因分析
当前流程：
1. `loadWithAuth()` 调用 `configCookieSync()` 注入 cookie
2. `configCookieSync` 是内存级设置，未调用 `saveCookieAsync()` 持久化到磁盘
3. WebView 实例销毁后，cookie 丢失
4. 下次进入时，`HttpUtil.cookieStore` 中的 cookie 虽然还在，但 WebView 的 cookie 管理器已经刷新

安卓版通常使用 `CookieManager.getInstance().setCookie()` + `CookieManager.getInstance().flush()` 来持久化。

### 修复方案
在 [ServiceWebPage.ets](entry/src/main/ets/pages/ServiceWebPage.ets) 和 [ClassTablePage.ets](entry/src/main/ets/pages/ClassTablePage.ets) 的 `loadWithAuth()` 方法中：
1. `configCookieSync` 之后，调用 `web_webview.WebCookieManager.saveCookieAsync()` 持久化 cookie 到磁盘
2. 在 `aboutToAppear` 加载页面之前，先确保已有 cookie 被恢复 — 调用 `WebCookieManager` 的 fetchCookieSync 验证 cookie 是否已存在
3. 页面跳转/重定向后也重新注入 token — 在 `onPageBegin` 中对新的 URL 域名也注入 cookie

```typescript
// loadWithAuth 末尾添加:
web_webview.WebCookieManager.saveCookieAsync()
  .then(() => { console.info('Cookies saved'); })
  .catch(() => {});

// onPageBegin 中注入新域名的 cookie:
.onPageBegin(() => {
  this.isLoading = true;
  this.injectCookiesForCurrentUrl();
})
```

## 4. 替换搜索框为 ImmersionSearch

### 当前状态
4 个搜索框 (HomeTab, ServiceTab, MessageTab, ScheduleTab) 使用自定义 `TextInput` + `Row` + `backgroundColor` 方案

### 目标方案
使用 `@tangs/components` 的 `ImmersionSearch` 组件（API 23+，与 Authenticator 项目一致）

### 参考实现 (Authenticator-main)
```typescript
ImmersionSearch({
  systemMaterialEffect: this.configuredMaterialEffect(),
  _height: HOME_SEARCH_HEIGHT,
  options: { placeholder: this.t('搜索令牌') },
  modifier: new HomeSearchModifier(
    this.primaryTextColor(),
    this.primaryTextColor(),
    (value: string): void => { this.searchText = value; }
  )
})
.height(HOME_SEARCH_HEIGHT)
.width('100%')
.clip(false)
```

其中 `HomeSearchModifier` 实现 `AttributeModifier<SearchAttribute>`：
```typescript
class HomeSearchModifier implements AttributeModifier<SearchAttribute> {
  constructor(textColor, hintColor, change) { ... }
  applyNormalAttribute(instance: SearchAttribute): void {
    instance.fontColor(this.textColor)
      .placeholderColor(this.hintColor)
      .onWillChange((value) => { this.change(value.content); return true; });
  }
}
```

### 修改文件
- [HomeTab.ets](entry/src/main/ets/pages/tabs/HomeTab.ets): 替换 `SearchBar`/`SearchBarInner` → `ImmersionSearch`
- [ServiceTab.ets](entry/src/main/ets/pages/tabs/ServiceTab.ets): 同上
- [MessageTab.ets](entry/src/main/ets/pages/tabs/MessageTab.ets): 同上
- [ScheduleTab.ets](entry/src/main/ets/pages/tabs/ScheduleTab.ets): 这个是"添加日程"输入框，不是搜索，保持 TextInput 或单独处理

### 需要新增
- 创建通用 `SearchModifier` 类（类似 Authenticator 的 `HomeSearchModifier`）在 `components/` 下
- 各 Tab 组件需要 `configuredMaterialEffect()` / `configuredMaterialType()` / `configuredMaterialLevel()` 方法（调用 MaterialConfig）

## 5. 优化 WebView 页面布局

### 问题
- ServiceWebPage 有悬浮按钮栏（返回+分享），WebView 内容通过 `injectSafePadding` 注入 padding-top 避让
- 这导致状态栏 → 按钮区 → 空白 → 页面内容的割裂感
- H5 页面内的导航栏无实际功能，只是 web 渲染的一部分

### 修复方案
在 [ServiceWebPage.ets](entry/src/main/ets/pages/ServiceWebPage.ets)：
1. **移除 `injectSafePadding`** — 不再注入 body padding-top
2. **移除悬浮按钮栏的空白间隙** — 按钮直接贴在状态栏下方
3. **状态栏填充方案** — 与 ClassTablePage 一致：通过 `StatusBarUtil.setStatusBarColor` 设置透明状态栏，WebView 内容从顶部开始渲染
4. **返回/分享按钮使用原生 ImmersionButton** — 见第6项

### ClassTablePage 对照
ClassTablePage 也是类似布局，但它只有返回按钮没有分享按钮。统一方案：
- 悬浮按钮区高度 = statusBarHeight + 8 + btnSize + 8
- 按钮栏用 `.position({ x: 0, y: 0 })` 定位在顶部
- WebView 全屏渲染，按钮浮动在上方
- 不注入 padding，让 H5 页面自然填充

## 6. 替换 H5 页面顶部按钮为原生组件

### 当前状态
ServiceWebPage / ClassTablePage 的返回/分享按钮使用 `Stack` + `SymbolGlyph`/`Text` + `backgroundColor('#66000000')` + `backdropBlur(20)` 自制

### 目标
使用 `ImmersionButton` 组件（已有 import），配合 `systemMaterialEffect`，视觉上与整体沉浸光感一致

### 修改方案
在 [ServiceWebPage.ets](entry/src/main/ets/pages/ServiceWebPage.ets) 和 [ClassTablePage.ets](entry/src/main/ets/pages/ClassTablePage.ets)：
- 返回按钮 → `ImmersionButton` with `SymbolGlyph($r('sys.symbol.chevron_backward'))` as content
- 分享按钮 → `ImmersionButton` with share icon/text as content
- 需要导入 `ImmersionButton` 和 `MaterialConfig`
- 按钮不再需要手动的 `backgroundColor('#66000000')` + `backdropBlur`

## 风险与兼容性

- **HdsTabs systemMaterialEffect**: API 23+（compatibleSdkVersion = 6.1.0(23)），无需 apiAvailable 保护
- **ImmersionSearch**: @tangs/components 1.5.3，最低 API 23，无需保护
- **configCookieSync**: API 26 新 4 参数版本，需 apiAvailable 保护回退到 setCookie
- **ImmersionButton**: @tangs/components 1.5.3，API 23+，无需保护
- **saveCookieAsync**: API 9+，无兼容性问题
