# 云上商工 · 鸿蒙移植 —— 接口交接文档

> 来源：从 APK 内 wgt 资源 `app-service.js`（uni-app 编译器 3.3.0）逆向提取，仅覆盖登录 + 门户 + 首页 + 核心服务。
> 说明：所有域名均指向**商丘工学院（sqgxy.edu.cn）**新开普智慧校园平台。`X-Id-Token` = 登录后服务端下发的 JWT。

## 一、登录（appletBase = https://cas.sqgxy.edu.cn/token/）

所有登录接口走 `_request.wexinRequest`，其请求头（`wexinHeaders`）：
```
X-Device-Info   = 设备特征串（brand + model + version 拼接）
X-Device-Infos  = {"packagename":<appId>,"version":<version>,"system":<system>}
X-Terminal-Info = "app"
X-Id-Token      = <JWT>（未登录为空串）
Content-Type    = application/x-www-form-urlencoded
Accept          = application/json
```

| 功能 | 方法与路径 | 参数 |
|---|---|---|
| 密码登录 | POST `/password/passwordLogin` | username, password, appId, deviceId, osType, geo（均明文，URL query） |
| 验证码登录 | POST `/passwordless/smsLogin` | —（短信验证码，需先 smsInit） |
| 获取 nonce | POST `/passwordless/smsInit` | — |
| 发送短信 | POST `/passwordless/smsSend` | — |
| 账号选择 | POST `/login/accountChoose` | accountId… |
| 微信联邦登录 | POST `/federation/federated/weixinminiprogram` | code… |

登录成功响应：`{ code: 100000, data: { accounts: [...] } }`；JWT 存在响应头 `X-Id-Token`。

> ⚠️ `appId` 构建时由模板 `APP_ID` 注入，JS 端用 `plus.runtime.appid`（= `__UNI__AA068AD`）。
> `packagename` 是服务器白名单校验的关键，需从原 APK 抓包确认真实值（见「待确认」）。

## 三、业务接口（GET/POST，均带 X-Id-Token）

### 首页 / 门户（baseUrl = portal-api）
- `GET /api/rest/mobile/v2/system/getResources` —— 资源列表（应用/服务入口，含各子系统 url）
- 今日课程 `GET {JiaoWuUrl}/ws/app-api/home/today-course-event`

### CMS 内容（CMSUrl = portal-api）
- 横幅 `GET /v2/cms/marqueeList/get`
- 公告列表 `POST /api/proxy/cms/api/rest/mobile/v2/content/list`
- 公告详情 `GET /api/proxy/cms/api/rest/mobile/v2/content/{id}`
- 栏目 `GET /api/proxy/cms/api/rest/mobile/v2/column/list`

### 课表 / 日程（baseUrl = portal-api）
- 学期列表 `GET /api/semester/list`
- 学期周次 `GET /api/semester/currentWeek`
- 课表 `GET /api/proxy/calendar/api/rest/mobile/v2/personal/schedule/get`
- 按日 `GET /api/proxy/calendar/api/rest/mobile/v2/personal/list`
- 日程增删改 `POST /api/proxy/calendar/api/rest/mobile/v2/personal/schedule/insert|update|delete`
- 课程库 `GET /api/courseList/list/`、`GET /api/kcxx/`
- 课程表按日 `GET /api/courseTable/day`

### 服务 / 收藏（baseUrl = portal-api）
- 常用服务 `POST /api/proxy/service/api/rest/mobile/v2/selectMyServicesByTypeId`
- 我的收藏 `POST /api/proxy/service/api/rest/mobile/v2/selectMyCollectServices`
- 最近使用 `POST /api/proxy/service/api/rest/mobile/v2/SelectLastUsedServices`
- 收藏/取消 `POST /api/proxy/service/api/common/mobile/v2/collect|uncollect`
- 人气/榜单 `POST /api/proxy/service/api/common/mobile/v2/popularServiceRanking`
- 记录使用 `POST /api/proxy/service/api/rest/mobile/v2/recordUseService`

### 消息（baseUrl = portal-api）
- 未读数 `POST /api/v1/messageCenter/getUnReadedCount`
- 消息列表 `POST /api/v1/messageCenter/listMessageRecord`
- 即时消息 `POST /api/v1/instantMessage/getAppInstantMessageList/new`
- 消息已读 `POST /api/v1/messageCenter/messageRecordReadedByAppId`

### 事务中心（baseUrl = taskUrl 或 formflow/ttc）
- 待办 `POST /api/ttc/center-list/getToDoList`、`getToDoListCount`
- 已办/我发起 `POST /api/ttc/center-list/getHandleList|getInitiateList`
- 办理详情 `POST /api/ttc/center-list/getHandleDetailList|getToDoDetailList`
- 个人任务 `POST /ttc/person-task/getPersonTask|getPersonTaskDetial|addPersonTask|editPersonTask`

### 个人中心（baseUrl = myServiceBase）
- 用户信息 `GET /api/v1/personal/me/user`
- 头像 `GET /api/v1/personal/user/info/portrait`
- 修改密码标记 `GET /api/proxy/personalData/api/rest/mobile/v2/userdata/mobile/isFirstChangePwd`
- 登录日志 `POST /api/v1/personal/user/log/authenticationLog`

## 四、响应结构约定

统一形如：
```json
{ "code": 100000, "msg": "ok", "data": { ... } }
```
- `code == 100000` → 成功
- CMS `content/list` 等返回 `{ datas: { <key>: { rows: [] } } }`（HiXD 的 `extractRaw` 可复用）
- 未登录/Token 失效时服务器返回 401 或跳登录页

## 五、待确认项（需要抓包原 APK）

1. **`appId` 真实值**（登录 + X-Device-Infos 的 packagename）—— 原 APK 构建注入，JS 内是 `APP_ID` 占位符。
   影响：服务器白名单是否校验该值。
2. **`JiaoWuUrl`（教务域名）** —— 大概率由 `getResources` 动态下发。
3. 登录参数 `deviceId` 的生成规则（可能是设备唯一标识）。
4. 原 App 的 `User-Agent` 特征串。

## 六、验证方式（低成本）

- 方式 A（推荐）：把原 APK 装回安卓手机，用 Charles/HttpCanary 抓一次登录 + 首页请求，记录实际 `X-Device-Infos`、`appId`、`X-Id-Token`、教务域名 → 全部照抄。
- 方式 B：鸿蒙端先实现「登录 → 存 token → 请求首页公告」，用自己账号直连验证。

> 合规提示：仅使用本人账号、仅个人日用，不做批量/未授权抓取。
